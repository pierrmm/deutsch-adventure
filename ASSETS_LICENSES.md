# Asset Sources and Licenses — Deutsch Adventure DE

All game assets used in Deutsch Adventure DE are sourced from open-source, public domain, and permissive CC0/MIT licensed repositories:

## 1. Phaser 3 Examples Assets
- **Source**: [Phaser Official Examples Repository (photonstorm / phaserjs)](https://github.com/phaserjs/examples)
- **License**: MIT / CC0 Public Domain
- **Assets Included**:
  - `dude.png` — 32x48 Platformer player character spritesheet (walk/turn/jump frames)
  - `coin.png` & `coin-anim.png` — Gold collectible coin & 16x16 4-frame rotating spritesheet
  - `star.png` — Star collectible and reward badge
  - `mushroom.png` — Mushroom creature (Piranha plant / Goomba style)
  - `block.png` — Brick block texture
  - `platform.png` — Grassy ground platform tile
  - `tree-european.png` — European village deciduous tree
  - `tree.png` — Alpine pine tree
  - `hearts.png` — Player health HUD icons
  - `bigsky.png` & `background1.png` — Alpine Bavarian sky and mountain backdrop
